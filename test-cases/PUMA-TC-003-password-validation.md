# TC-003 - Перевірка валідації пароля з кириличними символами
**Проєкт:**  PUMA  
**Тип:** Functional Testing  
**Пріоритет:** Medium

## Передумови

Відкрита сторінка реєстрації сайту PUMA

## Тестові дані

* Ім'я: Иван
* Прізвище: Иванов
* e-mail: тестова електронна адреса, яка ще не використовувалася для реєстрації
* Пароль: значення, що містить кириличні літери, цифри та спеціальний символ

## Кроки виконання

1. Заповнити поля імені, прізвища та електронної пошти валідними даними
2. У полі пароля ввести значення, що містить кириличні літери
3. Заповнити поле повторного введення пароля тим самим значенням
4. Перевірити реакцію системи на введений пароль

## Очікуваний результат

Якщо кириличні символи не підтримуються, система повідомляє про це зрозумілим повідомленням

## Фактичний результат

Пароль відхиляється, але повідомлення не пояснює, що кириличні символи не підтримуються
