# TC-001 - Перевірка локалізації головної сторінки після зміни мови сайту
**Проєкт:**  PUMA  
**Тип:** Functional Testing  
**Пріоритет:** Medium

## Передумови

Відкрита головна сторінка сайту PUMA

## Тестові дані

Мова сайту - російська

## Кроки виконання

1. Проскролити головну сторінку вниз
2. У футері головної сторінки змінити мову з української на російську
3. Оновити головну сторінку


## Очікуваний результат

Текст сторінки, зокрема банерів, відповідає вибраній мові сайту

## Фактичний результат

Частина банерів залишається українською мовою, тоді як меню сайту відображається російською
