# TC-001 - Пошук товару за назвою

**Проєкт:** Навчальний інтернет-магазин  
**Тип:** Functional Testing  
**Пріоритет:** High  

## Передумови

Відкрита головна сторінка інтернет-магазину.

## Тестові дані

Назва товару, який існує в каталозі.

## Кроки виконання

1. Ввести назву товару в поле пошуку.
2. Натиснути кнопку пошуку.

## Очікуваний результат

Відображаються результати пошуку, які відповідають введеному запиту.
