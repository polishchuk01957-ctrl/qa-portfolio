## API-001 - Створення, отримання та оновлення даних про тварину

**Проєкт:** Swagger Petstore  
**Тип:** API Testing  
**Інструмент:** Postman

## Мета перевірки

Перевірити створення запису про тварину через POST-запит, отримання даних за ID через GET-запит та оновлення даних через PUT-запит.

## Тестові дані

- ID: 867530
- Name: Chubaka
- Status: available

## Перевірка створення запису

**Метод:** POST

**URL:** https://petstore.swagger.io/v2/pet

**Тіло запиту:**

```json
{
  "id": 867530,
  "name": "Chubaka",
  "status": "available"
}
```

**Очікуваний результат:** сервер приймає дані та повертає створений запис

**Фактичний результат:** отримано HTTP 200 OK. У відповіді повернулися ID 867530, ім'я Chubaka і статус available

**Статус:** Passed


## Перевірка отримання запису

**Метод:** GET

**URL:** https://petstore.swagger.io/v2/pet/867530

**Очікуваний результат:** сервер повертає запис із відповідним ID та даними, які були передані під час створення

**Фактичний результат:** отримано HTTP 200 OK та ID 867530. Під час повторних запитів значення полів відповіді змінювалися. В одному із запитів повернулися ім'я Chubaka та статус available

**Статус:** Потребує додаткової перевірки

## Перевірка оновлення запису

**Метод:** PUT

**URL:** https://petstore.swagger.io/v2/pet

**Тіло запиту:**

```json
{
  "id": 867530,
  "name": "Chubaka",
  "status": "available"
}
```

**Очікуваний результат:** сервер приймає запит та повертає оновлені дані тварини

**Фактичний результат:** отримано HTTP 200 OK. У відповіді повернулися ID 867530, ім'я Chubaka та статус sold

**Статус:** Passed

### Повторна перевірка через GET

**Метод:** GET

**URL:** https://petstore.swagger.io/v2/pet/867530

**Очікуваний результат:** сервер повертає оновлені дані тварини

**Фактичний результат:** отримано HTTP 200 OK. У відповіді повернулися ID 867530, ім'я Chubaka та статус sold

**Статус:** Passed

## Висновок

Під час перевірки POST-запит повернув HTTP 200 OK та дані створеного запису. GET-запит дозволив отримати дані за ID. PUT-запит повернув HTTP 200 OK та оновлені дані зі статусом sold. Повторний GET підтвердив, що статус sold зберігся. Під час повторних GET-запитів також спостерігалися зміни значень полів, тому стабільність роботи API потребує додаткової перевірки
