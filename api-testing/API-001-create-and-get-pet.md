# API-001 — Створення та отримання даних про тварину

**Проєкт:** Swagger Petstore  
**Тип:** API Testing  
**Інструмент:** Postman

## Мета перевірки

Перевірити створення запису про тварину через POST-запит і отримання даних за її ID через GET-запит.

## Тестові дані

- ID: 867530
- Name: Chubaka
- Status: available

## Перевірка створення запису

**Метод:** POST

**URL:** https://petstore.swagger.io/v2/pet

**Тіло запиту:**

{

  "id": 867530, 
  
  "name": "Chubaka", 
  
  "status": "available" 
  
}


**Очікуваний результат:** сервер приймає дані та повертає створений запис

**Фактичний результат:** отримано HTTP 200 OK. У відповіді повернулися ID 867530, ім'я Chubaka і статус available

**Статус:** Passed

## Перевірка отримання запису

**Метод:** GET

**URL:** https://petstore.swagger.io/v2/pet/867530

**Очікуваний результат:** сервер повертає запис із відповідним ID та даними, які були передані під час створення

**Фактичний результат:** отримано HTTP 200 OK, ID 867530. Під час повторних запитів значення полів name і status змінювалися. В одному з останніх запитів повернулися ім'я Chubaka та статус available

**Статус:** Потребує додаткової перевірки

## Висновок

POST-запит успішно оброблено. GET-запит повертає запис за вказаним ID. Водночас стабільність даних потребує додаткової перевірки.
