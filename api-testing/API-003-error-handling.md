# API-003-Перевірка обробки помилок API

**Проєкт:** Swagger Petstore  
**Тип:** API Testing  
**Інструмент:** Postman

## Мета перевірки

Перевірити, як API обробляє неправильні дані та запити до неіснуючих записів

## 1. Перевірка неіснуючого ID

**Метод:** GET

**URL:** https://petstore.swagger.io/v2/pet/999999999

**Очікуваний результат:** сервер повертає HTTP 404 Not Found

**Фактичний результат:** отримано HTTP 404 Not Found та повідомлення `Pet not found`

**Додаткові перевірки в Postman:**
- HTTP-статус дорівнює 404
- Поле `message` містить `Pet not found`
- Поле `type` містить `error`
- Поле `message` має тип `string`

**Результат:** Passed

## 2. Перевірка POST-запиту

**Метод:** POST

**URL:** https://petstore.swagger.io/v2/pet

**Тіло запиту:**

```json
{
  "id": 867531,
  "name": "Chubaka",
  "status": "available"
}
```

**Очікуваний результат:** сервер повертає HTTP 200 OK та дані створеної тварини

**Фактичний результат:** отримано HTTP 200 OK. Сервер повернув дані тварини

**Додаткові перевірки в Postman:**
- HTTP-статус дорівнює 200
- Поле `name` містить `Chubaka`
- Поле `status` містить `available`
- Поле `id` має тип `number`
- Поля `id`, `name` та `status` присутні у відповіді

**Результат:** Passed. Усі 6 автоматизованих перевірок пройшли успішно

## Висновок

Під час тестування я перевірив GET-запит з неіснуючим ID та POST-запит для створення тварини

GET-запит повернув HTTP 404 та повідомлення про помилку

POST-запит повернув HTTP 200 та дані створеної тварини

Також я написав прості автоматизовані перевірки в Postman. Усі перевірки пройшли успішно
